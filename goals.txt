أهم ما تعلمته من الدروس

تعلمت كيف أستخدم Command Line للتعامل مع الملفات
والمجلدات عن طريق الأوامر بدل الماوس مثل إنشاء الملفات
والتنقل بين المجلدات ونسخها وحذفها. وتعلمت كمان الفرق
بين المسار الكامل والمسار النسبي.

فهمت أهمية Version Control وكيف يساعدنا في تتبع
التعديلات والرجوع للنسخ السابقة إذا صار خطأ.
وعرفت الفرق بين Git وGitHub وأن Git يستخدم لتتبع
التعديلات على الجهاز بينما GitHub يساعدنا في رفع
المشاريع وحفظها ومشاركتها مع الآخرين.

تعلمت أوامر Git الأساسية مثل git init وgit status
وgit add وgit commit وgit push، وكيف أربط مشروعي
مع GitHub وأرفع عليه التعديلات الجديدة.

وأخيرًا عرفت أهمية Git وGitHub في تنظيم المشاريع
وتسهيل العمل الجماعي، وكيف ممكن أستخدم GitHub
لعرض مشاريعي والاستفادة منها مستقبلًا في التوظيف.

أتعلم كيف أستخدم GitHub Issues
 لتنظيم المهام وتتبع الأخطاء
  والمشكلات في مشاريعي البرمجية.
